# یادداشت محدودیت‌ها و اعتبارسنجی 4.0.1-beta.2

- مطابق تصمیم صاحب پروژه، مقدارهای اولیهٔ Admin/Admin و منطق ورود اولیه **تغییر نکرده‌اند**. نصب‌های تازه همچنان باید از نظر دسترسی فیزیکی/شبکه‌ای و تغییر اعتبارنامه مدیریت شوند.
- installer ویندوز **امضای Authenticode ندارد** و راستی‌آزمایی امضای updater فعال نشده است. مسیر جایگزین دانلود تنها اندازه، نشانی مجاز و SHA-256 گزارش‌شده در API انتشار GitHub را برای همان فایل EXE بررسی می‌کند؛ این هش از همان کانال انتشار می‌آید و هویت ناشر را اثبات نمی‌کند. اگر API برای asset هش ندهد، مسیر جایگزین با خطا متوقف می‌شود. تا فراهم‌شدن امضا، به‌روزرسانیِ خودکار نباید هم‌ارز زنجیرهٔ تأمین امضاشده تلقی شود.
- پذیرش گواهی self-signed دستگاه پس از نمایش fingerprint و تأیید صریح کاربر فقط تا پایان همان اجرای برنامه اعتبار دارد. fingerprint را باید از راه مستقلی با مدیر دستگاه تطبیق داد. اعتبارسنجی در برابر تجهیزات واقعی و سناریوهای تعویض گواهی در ویندوز هنوز لازم است.
- `npm ci` و دروازهٔ `npm audit` اجرا شدند. گزارش audit هنوز **۸ مورد moderate و ۵ مورد high** نشان می‌دهد؛ پنج مورد high زنجیرهٔ استثنای محدودِ توسعه‌ای `braces` تا ۲۰۲۷-۰۱-۳۱ هستند. موارد moderate عمدتاً وابستگی‌های زنجیرهٔ بسته‌بندی `electron-builder` / `sprintf-js` هستند؛ نسخهٔ سازگارِ بدون یافته در مسیر فعلی npm audit پیشنهاد نشد. استثنا و وابستگی‌ها باید پیش از موعد دوباره بررسی شوند؛ قبولی audit gate به معنای پاک‌بودن گزارش کامل نیست.
- منبع JavaScript نگهداری‌شدهٔ پروژه و تست‌ها به خانوادهٔ TypeScript منتقل شده‌اند؛ کد ثالث vendored و Agent بومی C++ مستثنا هستند. پروژه‌های `tsconfig.tests.json`، `tsconfig.playwright.json`، `tsconfig.renderer.json` و `tsconfig.config.json` فعلاً با `noCheck` خروجی می‌سازند؛ موفقیت `tsc` در آنها **typecheck کامل نیست**. Electron و اسکریپت‌ها جداگانه typecheck شده‌اند و آزمون‌های runtime هم اجرا شده‌اند.
- تست‌های محلی روی Linux: build، lint، format، typecheck، واحد، Electron-as-Node، مرورگر Chromium و audit gate موفق شدند. build بومی Agent و installer ویندوز در Linux ممکن نیستند؛ workflow ویندوز باید آنها و آزمون واقعی Windows Agent را پیش از انتشار asset اجرا کند. این نتایج جای تست دستی نصب، امضا، VPN/SMB و تجهیزات واقعی را نمی‌گیرند.
